CoreFitness is a gym portal where a user can register an account, log in, create a membership, view available classes, and book those classes. The system should store information about users, memberships, classes, and bookings in a database.

The system consists of a Web application built in ASP.NET Core MVC that is responsible for presentation, business logic, and communication with the database.
